## Currently building

- **[SealOS](https://github.com/xd-dbug/Capstone)** — a hobby x86_64 kernel in Rust (capstone). UEFI boot, higher-half paging, a kernel heap, and a preemptive round-robin scheduler are working; Ring 3, syscalls, and a shell are next.
